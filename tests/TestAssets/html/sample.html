Sync

Quill keeps your notes the same on every device you sign in to. Changes are sent to the sync service as soon as you stop typing, and other devices pick them up within a few seconds when they are online.

HIDDEN_TEXT This paragraph is not shown.

How sync works

Each note is stored as a small file. When you edit a note, Quill uploads only the parts that changed, which keeps sync fast even on a slow connection.
Attachments are uploaded separately, in the background.

  • Notes sync as soon as you stop typing.
  • Attachments sync in the background:
    • images first,
    • then other files.
  • Settings sync once a minute.

Conflicts

A conflict happens when the same note is changed on two devices before either change has synced. Quill keeps both versions and marks the note so you can choose which one to keep.

To see every note with a conflict, run this search in the command palette:

is:conflict
sort:modified
